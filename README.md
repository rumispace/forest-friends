# 숲속 친구들 탐험대

7~8세용 3D 자연 탐험 미션 게임 (Three.js, 설치 없음)

## 실행
    bash start.sh
화면에 나온 주소를 같은 Wi-Fi 의 iPad Safari 에서 연다.

## 이야기 (1부: 잿빛 마법사 스모기)
1장 숲 → 2장 계곡 → 3장 바닷가, 미션 23개. 장마다 스모기가 훔쳐 간 구슬(🟢🔵🟡)을 되찾는다.
구슬을 잃은 지역은 색이 바래고, 친구를 도울수록 색이 돌아온다.
미니게임: 도토리 줍기 · 장수풍뎅이 힘겨루기 · 쓰레기 건지기(헤엄) · 소라 껍데기 찾기 · 스모기 연기 날리기
2부(먹구름 대마왕) 예고로 끝난다. 이야기는 story.json 의 missions 에 이어 붙이면 된다.

## 조작
- iPad·휴대폰: 손가락을 대고 끌면 걷기, 톡 = 그곳으로 가기, 친구를 꾹 = 관찰
- PC: 마우스로 똑같이 + 방향키·WASD 로 걷기, 스페이스 = 대화 넘기기

## 올리기
    bash deploy.sh "바꾼 내용"
→ https://rumispace.github.io/forest-friends/ (1~2분 뒤 반영, iPad 는 다시 열면 자동으로 새 버전)

## 2부: 먹구름 대마왕
4장 동굴(박쥐·도롱뇽·오소리) → 5장 갯벌(짱뚱어·농게·저어새) → 6장 눈 덮인 산(멧토끼·산양·수리부엉이) → 7장 대마왕 결전.
햇빛 조각 ☀️ 세 개를 모아 해님을 구한다. 대마왕 부하 '번개 꼬마 찌릿이', 친구가 된 스모기가 돕는다.
새 미니게임: 박쥐 메아리 놀이(소리 듣고 따라 누르기) · 빛 버섯 · 조개 숨구멍 · 눈 위 발자국 따라가기.
지형: 숲 언덕, 오르막 눈산, 지붕 덮인 동굴(들어가면 지붕이 사라지고 어두워짐), 오소리 땅굴, 짱뚱어 구멍.
날씨: 2부 동안 먹구름·비, 눈산은 눈, 끝나면 무지개.

## 지도
숲(가운데) → 계곡(위, 숲 미션을 마치면 열림) → 바닷가(오른쪽, 계곡 미션을 마치면 열림)
미션 12개: 숲 6 · 계곡 3 · 바닷가 3

## 대사·도감 고치기
1. `story.json` 의 문구를 고친다
2. `python3 make_voice.py` → 바뀐 대사만 성우 음성(voice/)을 새로 만든다
3. index.html 의 `?v=` 숫자를 올리면 iPad 가 새 버전을 받는다
아빠 목소리로 바꾸려면 voice/index.json 에서 대사의 파일 이름을 찾아 같은 이름 mp3 로 덮어쓰면 된다.

## 파일
- index.html / style.css / game.js / story.json
- voice/ (성우 음성, make_voice.py 로 생성)
- lib/three.module.min.js (three r170, 오프라인 동작용)
